# LP再構成 — 2026-10-05

## メッセージと順序

中心は「調べるAIから、仕事が進むAIへ。」。AIアカウントの配布後に、現場で何が変わったかを問い、会社の散らばった業務をつなぐ価値を伝える。

1. 製品の主張とDashboardの実画面
2. 既存のAI利用に関する3つの問い
3. Dashboard / Chat / Skills / Agents / 業務アプリの機能ギャラリー
4. 紹介動画＋既存の6本のショート動画
5. 会話から仕組みを作る実画面・作成例と、段階的な拡張
6. ひとつの業務から始める導入支援
7. 自社開発管理の実践：依頼→プラン→人が承認→AI実装・ステージング→スタッフ検証→PR→人がマージ
8. 組織・権限・監査・連携
9. 公開中LPと同じ料金と、業務相談への入口

開発管理は自社の実案件での取り組みとして扱い、一般企業向けの最初の訴求にはしていない。人が担う3つの判断と将来の構想を分け、未計測の削減率・利用率・ROIは掲載しない。業務アプリ生成は開発中と表示。説明用UI・導入写真にはイメージの注記を付ける。

## 表現と操作

- 大きな見出し、余白、実画面を中心にした明るい配色。参考はAppleのiPhoneページの視線誘導と動き。Appleの素材は使用しない。
- スクロール時に一度だけ画像や本文がフェードしながら上がる。
- 機能はクロスフェード付きのタブ。左右キー、Home/Endで操作できる。
- 動画はクロスフェード付きの7本のカルーセル。矢印、選択ボタン、横スワイプで切り替える。再生を押した時だけYouTubeのiframeを読み込む。
- 切り替え・画面外へのスクロールで再生を停止。動画の自動切り替えは行わない。YouTubeへ直接開くリンクも提供。
- スマホ用ナビゲーション、言語切り替え（日本語・英語・ベトナム語）、本文スキップリンク、フォーカス表示。
- OSの「動きを減らす」設定では移動・スケール・スムーススクロールを抑える。
- Advisorは遅延読み込み。公開環境では同じホストの `/api`、ローカルでは従来どおり4192を使う。旧ホストへの固定を除去。

## 検証

`npm run build` と `tsc --noEmit --incremental false`。

本番向けビルドをVite previewで開き、PC（1280px）とスマホ（390px）で実画面を確認。画像の読み込み、横幅、タブのクリック・キーボード操作、モバイルメニュー、言語切り替え、動画の選択とYouTube埋め込み再生を確認。

公開中LPから確認した動画IDと料金（800円・1,000円・3,000円）を使用。相談リンクは公開中の `/contact/`。Advisorのサーバー回答や問い合わせ送信は今回の表示検証の対象外。
